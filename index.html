How I make decisions

Three calls I would make again.

  1. Share the core, configure the edges

    One shared core with market-specific configuration, so a new market is a setup, not a project.

    Servicing platform

  2. Fix success criteria before launch

    Adoption, satisfaction and default rate against control, agreed before the experiment, so results end debates.

    Airtime

  3. Treat friction as a signal

    Borrowers read some friction as safety. We added proof of each transaction instead of removing steps.

    Debit payments
